## SAFETY

- Gerçek `.env`, credential store, shell history, process environment **okunmadı/yazdırılmadı**;
  kullanıcıdan secret istenmedi.
- PDF **üçüncü taraf servise upload edilmedi**; yalnız yerel stdlib extraction.
- Private key, mnemonic, signer, wallet veya chain-write yüzeyi **oluşturulmadı**.
- Ağ yalnız resmî kaynak okuması için kullanıldı (GitHub API/raw, ACP repo, Builder Hub,
  npm registry). Remote script/eval çalıştırılmadı.
- `sudo`, global install, `curl | sh`, force flag, destructive delete **kullanılmadı**.
  Poppler kurulumu bu nedenle **reddedildi**; stdlib çözüm yazıldı.
- Subagent, background task, watch mode, uzun yaşayan server **başlatılmadı**.
- Git durum değiştiren hiçbir komut çalıştırılmadı (`add/commit/push/...` yok).
- Geçici dosyalar yalnız scratchpad dizininde; proje dizinine yazılmadı.

   doğru mekanizma `.gitignore`'dur. Kullanıcıya soruldu, **`.gitignore` onaylandı** ve uygulandı.
   Doğrulandı: `git check-ignore` → `.gitignore:3`.

   git commit/push'u **kapsam dışı** bırakır. Kullanıcıya soruldu, **"PROMPT 00'a sadık kal"**
   seçildi. Commit **atılmadı**; talimat sonraki milestone'dan itibaren geçerlidir
