## DECISIONS

- Evidence schema `ictt-sentinel/evidence/v1`; domain-separated SHA-256, NFC/key-order
  canonical core. Bigint decimal string; JSON structural count'ları güvenli integer olarak
  doğrulanıp hash sırasında tek decimal gösterime çevriliyor. Presentation hash dışında.
- Verifier yalnız aggregate'e verilen hazır PASS/FAIL değerlerine güvenmez: ERC20 Gate A/B
  gerçekten çalışır; tam proof, rule projection ve tüm verdict alanları karşılaştırılır.
- Build kimliği gerçek artifact checksum'ıdır; `buildCommit: artifact-addressed` Git SHA iddiası
  değildir. `--version --json` ve evidence producer aynıdır. Source-lock dosyası ayrıca hash'lenir.
- Trust boundary: RPC dürüstlüğü, operatör attestations, source-lock'un dışarıdan güvenilirliği
  veya native supply varsayımları offline kriptografik olarak doğrulanmaz. Hash'in dışarıda
  güvenilir şekilde tutulması operatör sorumluluğudur; dosyayı bütünüyle yeniden yazan biri yeni
  hash üretebilir. Verifier geçmişteki fixture değerlendirmesini yeniden üretir, bugünü ölçmez.
- JSON ve HTML ayrı atomik dosyalardır; birlikte transaction değildir. Private root ve temp
  ownership doğrulanır. SIGKILL/power loss temp bırakabilir; yabancı dosya temizliği yapılmaz.
- `pnpm --filter … exec`, ölçümde non-zero 2/3 kodlarını 1'e dönüştürdü. README bunun yerine
  doğru exit ve JSON'u koruyan exact root script `pnpm --silent run cli -- …` kullanıyor.
- `doctor` eksik ayarda 5, doğrulanmamış kontrollerde 3 verir; asılsız `ready: true` yok.
  `discover` eksik canlı collector yerine kurgusal projection olduğunu açıklar ve 3 verir.
- Native motorunun codec/observation hattı henüz bu evidence sürümüne bağlanmadı; ERC20 desteği
  native desteğiymiş gibi genellenmedi.
